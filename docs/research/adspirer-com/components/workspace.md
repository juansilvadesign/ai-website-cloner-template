# Agent workspace

- **Role:** instruction for connecting an AI platform to Adspirer.
- **Controls:** nine compact icon tabs; active tab is `#1067fe` with white label, inactive tabs are transparent dark text. Tabs have pill shape and a fast ~160ms transition.
- **Desktop:** 928×448px translucent white guide panel with 16px radius and a deep soft shadow. Title is 48px/1.2.
- **Phone:** tabs scroll horizontally, content panel remains readable and steps stack.
- **Content states:** each platform changes title, numbered steps, endpoint/code block, and safety note. The Codex state is recorded in `raw/adspirer-workspace-codex-state.json`.
