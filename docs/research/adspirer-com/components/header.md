# Header and navigation

- **Role:** persistent entry point for product navigation and acquisition CTAs.
- **Desktop:** 97px tall, 6vw / ~86px side padding at 1440px; three-column alignment puts the wordmark left, nav center, actions right. Wordmark measures about 213×40px.
- **Phone and tablet:** 72px high with 20px inline padding. Wordmark is about 152×25px; only the 44px menu button remains.
- **Visual rules:** `#f6f8fa` field, black text, 14px nav labels, outlined peach “Contact Sales” and black “Get Started” buttons.
- **States:** a desktop menu surfaces at y≈76px with a 16px radius, translucent white panel, shadow, selected trigger state, outside-click/Escape close. Mobile menu becomes an opaque panel with close control.
