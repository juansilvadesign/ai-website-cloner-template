# Using the Spaceship system

## Read Order

Read `DESIGN.md`, then `tokens.css`, then `components.html`. Use the source
evidence if a decision needs to be traced to the target site.

## Design Highlights

- Deep black page canvas and raised charcoal product surfaces.
- Electric blue only for conversion, selected state, and atmospheric light.
- Spaceship Sans in a bold, tight display scale.
- Large 24–32px radii with soft inset light rather than hard outlines.
- Editorial media occupies whole visual panels; copy remains concise.

## Do

- Use declared variables from `tokens.css` for reusable visual values.
- Preserve wide visual breathing room around the hero and section headings.
- Pair a dominant action with a calm neutral control.
- Use the supplied assets as full-bleed visual surfaces, not thumbnail art.

## Avoid

- Do not introduce a second color system or generic sans family.
- Do not use rounded cards in the immersive hero area.
- Do not turn the scroll-story into dense text blocks.
- Do not hide meaningful actions behind icon-only controls.
